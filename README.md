# ShareGuard v0.6

SNS·메신저에 공유할 사진과 게시글의 개인정보 노출 후보를 검사하고 사용자가 보호할 영역을 직접 선택하는 웹앱입니다.

**서비스:** https://shareguard-two.vercel.app/

## 핵심 기능
- JPG/JPEG, PNG, WebP의 주요 메타데이터 검사 및 저장 후 재검사
- 한국어·영어 OCR(Tesseract.js)을 사용해 사진 속 문자 인식 및 개인정보 후보 생성
- 한국 도로명·지번 주소, 공백·하이픈이 섞인 휴대전화·일반전화 번호 탐지 보완
- 주변 문맥을 이용해 '사업장 정보 추정'과 '개인 거주지 연관 의심' 구분
- 탐지 후보별 위험도·판단 근거·권장 조치, 가림 ON/OFF
- 사용자 지정 영역 및 스티커·모자이크·블러·불투명 가림
- 게시글 개인정보 탐지, 원본·편집본 비교, 사진 다운로드

## 제한사항
- OCR 및 문맥 분류는 부정확할 수 있으며 실제 개인정보 소유자나 공개 여부를 증명하지 못합니다.
- 사업장 관련 표현이 있다고 반드시 공개 가능한 주소·전화번호는 아닙니다. 최종 공개 판단은 사용자에게 있습니다.
- 얼굴·차량 번호판·건물에 대한 AI 객체 자동 인식은 미구현입니다.
- OCR은 브라우저에서 실행되며 처음 실행할 때 외부 CDN에서 엔진·언어 데이터를 다운로드합니다. 원본 이미지는 OCR 서비스로 업로드하지 않습니다.
- OCR 탐지 후보 0개와 GPS 미발견은 안전함을 의미하지 않습니다.

## 테스트
`node --test tests/privacy-rules.test.cjs` — 예시 데이터 10건의 규칙 기반 탐지 테스트.

브라우저 모의 OCR 통합 테스트에서 주소·전화번호 후보 생성, 문맥에 따른 기본 가림 ON/OFF, 줄바꿈 주소 처리, UI 근거 표시를 확인했습니다. 실제 사용자 사진에 대한 전체 탐지율은 미검증입니다.
