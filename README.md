# ShareGuard

SNS·메신저에 사진과 게시글을 공유하기 전에 개인정보 노출 후보를 확인하고, 사용자가 원하는 영역을 직접 보호하는 웹앱입니다.

**실행:** https://shareguard-two.vercel.app/

## v0.4 주요 기능

- 사진의 JPEG·PNG·WebP 주요 메타데이터 확인과 저장 후 재검사
- 한국어·영어 OCR(Tesseract.js 6.0.0)으로 사진 속 문자 인식, 전화번호·이메일·인증정보 등의 가림 후보 영역 제안
- 탐지 영역별 ON/OFF 및 불투명 가림·블러·모자이크·스티커 선택
- 직접 영역 추가·자르기·원본/편집본 비교·다운로드
- 게시글 개인정보 규칙 탐지·마스킹
- 미검사 상태에서 사진 저장 시 확인 경고

## 실행 방법

루트의 `index.html`을 Chrome에서 열거나 위 배포 주소에 접속해 주세요. 사진 업로드 후 **사진 글자 검사**를 실행하고, 우측 후보별 ON/OFF를 확인한 뒤 편집 및 저장해 주세요.

## 개인정보 및 한계

OCR은 사용자 브라우저에서 실행되며 원본 사진은 OCR 서버에 업로드하지 않습니다. 첫 실행 시 OCR 코드·한국어/영어 언어 데이터를 외부 CDN에서 다운로드하므로 인터넷이 필요합니다.

OCR은 문자를 놓치거나 잘못 인식할 수 있으며, **얼굴·건물·간판을 객체로 자동 인식하는 기능은 아직 구현하지 않았습니다**. 메타데이터 검사에도 한계가 있으므로 안전을 보장하지 않습니다.

## 검증

- JS 구문 검사 통과
- Chromium 테스트: OCR 반환 데이터를 모의 입력하여 가림 후보 2건 생성·ON/OFF·원본 비교 통합 흐름 확인
- Chromium 테스트: OCR 실패 시 수동 영역 선택 및 PNG 저장 확인
- **실제 CDN OCR 엔진 다운로드 및 한국어 OCR 인식 정확도는 아직 미검증**입니다.
