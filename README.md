# ShareGuard v0.5

SNS·메신저·AI 서비스에 공유할 사진과 게시글의 개인정보 노출 후보를 검사하고, 사용자가 각 영역의 가림 여부를 선택하는 브라우저 웹앱입니다.

**웹앱:** https://shareguard-two.vercel.app/

## 사진 분석 흐름

1. JPG/JPEG, PNG, WebP 사진을 업로드하면 **EXIF/GPS 검사와 OCR 문자 검사가 독립적으로 진행**됩니다.
2. OCR은 한국어/영어 텍스트를 읽고 전화번호·이메일 등 규칙에 부합하는 개인정보 가림 후보를 표시합니다.
3. **인식된 글자 수**와 **개인정보 후보 수**는 별개로 표시되며, 사용자는 각 후보의 가림을 ON/OFF하고 가림 방식을 선택할 수 있습니다.
4. 사용자가 직접 영역을 추가하거나, 편집본 미리보기/재검사 후 저장할 수 있습니다.

## v0.5 개선

- 사진 업로드 후 OCR 자동 실행 (v0.4는 버튼을 눌러야 시작했습니다).
- 작은 글자 대응을 위해 인식용 캔버스를 업스케일 (최대 긴 변 3400px, 680만 픽셀).
- OCR 원문 확인(접기/펼치기), 문자 수와 가림 후보 수 개별 표시.
- OCR 엔진 오류, 텍스트 미검출, 텍스트 인식/좌표 누락 상황 구분.
- EXIF/GPS 정보가 없어도 OCR 검사 수행.

## 한계와 개인정보 보호

- OCR 인식 후보가 0개라도 안전을 보장하지 않습니다. 작은 글씨·흐린 이미지 등에서 인식 오류가 발생할 수 있습니다.
- 현재 **AI 얼굴·건물·번호판 객체 자동 인식은 미구현**입니다.
- OCR은 사용자의 브라우저 내부에서 실행합니다. 처음 실행할 때 OCR 엔진과 한국어/영어 언어 데이터를 외부 CDN에서 다운로드하며 **원본 이미지 데이터를 OCR 서비스에 전송하지 않습니다**.
- 기존 JPEG/PNG/WebP의 주요 메타데이터 검사에도 형식별 한계가 있습니다.

## 기술 검증 상태

- JavaScript 구문 검사: 통과
- Chromium 모의 OCR: 자동 실행 → 휴대전화/이메일 2개 가림 후보 생성 → 미리보기: 통과
- OCR 미검출/좌표 누락/엔진 오류 상태 구분 테스트: 통과
- GitHub/Vercel 배포: 확인
- 실제 한국어/영어 OCR 엔진 다운로드·인식 정확도: **자동 외부 접근이 인증에 차단되어 미검증**
