## 수동 브라우저 테스트가 추가로 필요한 항목

- Windows Chrome에서 샘플 사진을 불러와 캔버스 위에 영역 지정하기
- 가림 ON/OFF와 스타일 변경에 따라 미리보기 변화 확인
- 스티커 표시 및 자르기/비교 슬라이더 동작 확인
- JPEG 저장 후 원본 EXIF와 내보낸 JPG의 메타데이터 대조
- 키보드 탐색, 모바일 터치, 대용량 이미지 성능

브라우저 자동 검증 환경에서 Chromium 실행이 시간 초과되어 수동 조작 테스트를 완료했다고 주장하지 않습니다.
