# ShareGuard v0.6 검사 규칙 보강 결과

- 업데이트: 2026-10-23
- 구현: 도로명·지번 주소 형태 검사, 휴대전화/일반전화 공백·하이픈 대응, 인접 OCR 줄 연결, 사업장·거주지 문맥 기반 후보 위험도 분류, 근거 및 권장 조치 UI 노출

- Chromium 모의 OCR 테스트: 사업장 관련 도로명 주소·일반전화 후보 생성 2건, 줄바꿈 주소 후보 생성, 후보별 가림 ON/OFF와 근거 표시 확인. JavaScript 콘솔 오류 미발생
- 배포 전 한계: 실제 사진의 OCR 정확도와 주소 탐지율은 별도 검증 필요
- 기존 한계: 얼굴/건물/간판 객체 인식 미구현; GPS 미발견은 안전 판정 아님
