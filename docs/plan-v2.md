# ShareGuard — plan.md v2

**변경일:** 2026-10-22  
**상태:** 정적 웹앱 MVP 0.1 코드 및 테스트 작성 완료, 실기기 조작/배포 미완료

## 목표

SNS·메신저·AI 서비스에 공유할 사진과 게시글의 개인정보·위치 노출 단서를 검사하고, **사용자가 직접 가릴 부분과 방식을 선택**해 안전한 공유를 돕는 웹앱.

## 핵심 기능 (3개)

1. **개인정보·위치 노출 단서 분석:** JPEG EXIF/GPS 검사, 글 속 민감정보와 생활 패턴 단서 검사. 후속 단계에 얼굴·간판 등 AI 이미지 인식 추가.
2. **사용자 선택형 보호 편집:** 개별 가림 영역 ON/OFF, 블러·모자이크·불투명 가림·감성 스티커 선택, 직접 지정 및 자르기.
3. **위험 설명·재검사·내보내기:** 검출 근거와 우려 안내, 편집 전후 비교, JPEG 재인코딩 후 EXIF/GPS 재검사 및 보고서 저장.

## v1 대비 변경된 내용과 그 이유

- **일괄 가림 → 개별 ON/OFF:** 카페 간판이나 본인 얼굴 등 의도적으로 공개하려는 부분까지 삭제하면 SNS 게시 목적이 훼손됨.
- **불투명 사각형만 → 스티커·블러·모자이크 선택:** 사용자가 개인정보 보호와 SNS 사진의 감성을 함께 관리할 수 있도록 함. 단, 고위험 정보에는 불투명 가림·자르기 권장.
- **전체 사용자 안내 문구 존댓말:** 서비스의 전문성 및 일관성을 확보함.
- **자동 AI 영상·이미지 인식은 별도 단계:** 실제 분석 모델을 통합하지 않은 상태에서 자동 인식한다고 주장하지 않기 위함.
- **React/Vite 대신 무의존성 정적 MVP:** 실행 환경의 외부 패키지 설치가 제한되어 빠른 작동과 재현성을 우선함. 기술 전환은 안정적인 개발 환경에서 별도로 판단.

## 현재 실제 구현

- JPG/PNG/WebP 업로드, JPEG EXIF 검사, 테스트용 GPS 샘플
- 게시글 민감정보 규칙 및 복합 문맥 경고
- 사용자 지정 가림 영역, 영역별 ON/OFF, 스티커/모자이크/블러/불투명 가림
- 자르기, 원본/편집본 비교, EXIF 제거 후 JPEG 저장, JSON 요약
- 자동 테스트 9개 통과

## 미완료·유의사항

- 모델을 이용한 얼굴/표지판 자동 탐지, OCR, 사진 자체의 위치 추론은 구현 전
- PNG/WebP 원본 EXIF 전체 검사는 미지원
- 브라우저 조작 E2E 및 Vercel 배포는 미완료
- 사진은 서버에 업로드하지 않으며, 실제 사용자의 보호 효과는 테스트 기반으로 검증해야 함
