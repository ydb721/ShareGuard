# ShareGuard v0.4 OCR 구현 및 검증

- 날짜: 2026-10-23
- 변경: 한국어/영어 OCR 검사 버튼, 문자 패턴 추출, 이미지 좌표 가림 후보 생성, 실패 시 수동 가림 유지
- 지원 이미지: JPEG, PNG, WebP
- 기본 보호: 높은 위험 후보 가림 ON / 중간 위험 후보 OFF (사용자가 수정 가능)
- 개인 정보: OCR 엔진은 기기 내 실행, 학습 데이터와 엔진만 CDN 다운로드
- 테스트 (모의 OCR 엔진): 전화번호·이메일 2건 후보 생성, 스위치 전환, 미리보기
- 테스트 (OCR 오류 주입): 오류 상태 표시, 수동 영역 지정, PNG 다운로드
- 구문 검사: Node.js --check 통과
- 미검증: 배포 브라우저에서 실제 Tesseract.js와 한국어/영어 언어 모델 로딩 및 정확도
- 미지원: 얼굴·차량 번호판·건물 등의 AI 객체 탐지. 미탐 가능성 안내 필수
